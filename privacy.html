SCALE CS2 Inventory Value & Exporter — Privacy Policy

Effective date: September 22, 2026

SCALE CS2 Inventory Value & Exporter helps users read, value, and export their Counter-Strike 2 inventory from Steam Community. The extension is designed to minimize the data sent outside the browser and does not perform trades, purchases, sales, deposits, withdrawals, or other financial actions.

1. Data processed in the browser

When the user activates the extension on Steam Community, the extension may read inventory and page content needed to identify the user's CS2 inventory and produce local reports. Depending on what Steam provides, this can include item names, item and asset identifiers, collection, rarity, exterior, float value, paint seed, paint index, StatTrak or Souvenir status, tradability, marketability, trade-lock information, stickers, charms, inspect data, and other technical item metadata.

This inventory data is used to build the on-screen result and the JSON and Excel files requested by the user. Exported files are saved locally through the browser and are not automatically uploaded to SCALE.

2. Data sent to SCALE for valuation

To obtain market estimates, the extension sends only the item attributes needed to match an item against SCALE's market database: a per-item client identifier used to match the response to the local item; market_hash_name; float value when available; paint seed when available; and paint index when available.

The extension does not send the user's Steam password, Steam Guard or two-factor authentication codes, Steam cookies, sessionid, Steam API keys, Trade URLs or tokens, payment information, bank information, or raw Steam authentication credentials to SCALE.

3. How valuation data is used

The transmitted item attributes are used only to return market-based estimates, float-aware comparables, and evidence-gated pattern information. SCALE maintains its own market-data infrastructure and does not require the user's personal API keys for valuation.

SCALE does not intentionally persist the user's inventory request as a user profile and does not sell inventory data or use it for advertising, credit, lending, or unrelated profiling. Infrastructure providers may process limited technical request metadata, such as network and request logs, for security, reliability, and service operation.

4. Market-data providers

SCALE uses external market information to build and refresh its global pricing datasets. The current production valuation service uses global market data maintained by SCALE from market-data sources. User inventory requests are matched against SCALE's stored datasets; they are not forwarded to third-party marketplaces as part of the normal valuation request.

5. Permissions

The extension uses activeTab and scripting so it can read the Steam Community page only when the user invokes the extension and run the local extraction logic needed for the requested inventory export. Host access is limited to Steam Community and SCALE's valuation service.

6. Remote code

The extension does not download or execute remote JavaScript, WebAssembly, or other executable code. Network requests retrieve data only. The extension's executable code is included in the submitted extension package.

7. Data retention

SCALE does not intentionally retain the item-level valuation request payload after the valuation response is produced. Global market datasets, pricing observations, and market-comparison data are retained independently because they describe market activity rather than a specific user's inventory.

Files exported by the extension remain on the user's device until the user moves or deletes them.

8. Data sharing and sale

SCALE does not sell personal information or inventory data. SCALE does not share item-level user requests with advertisers or data brokers. Service infrastructure providers may process data only as needed to host, secure, and operate the valuation service.

9. Security and user responsibility

Users should never provide Steam passwords, Steam Guard codes, browser cookies, session identifiers, API secrets, Trade URL tokens, or financial credentials to SCALE. The extension does not require those credentials for its normal inventory valuation and export functionality.

10. Changes to this policy

This policy may be updated if the extension's data practices, permissions, infrastructure, or functionality materially change. The effective date at the top of this page will be updated when a revised policy becomes active.

11. Contact

For privacy questions, use the developer support contact displayed on the SCALE CS2 Inventory Value & Exporter listing in Microsoft Edge Add-ons.
